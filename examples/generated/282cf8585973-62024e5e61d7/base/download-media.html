Download selected media

Prepare a browser download from selected archive media. This guide covers the remote method; drive and advanced transfers require separate qualification.

Prerequisites

  • Archive remoteTransfer must be enabled and your signed-in account must have transfer permission.
  • Use Chrome or Edge on the destination device with a save-location picker.
  • Select media whose requested rendition is ready; missing renditions are not replaced with originals.

Steps

1. Choose media and rendition

Select archive media and choose Transfer. In Rendition choose an available Original, Web proxy, or Edit proxy when enabled.

Expected: The preview reports the requested and ready files. Missing renditions are identified.

2. Prepare download

Choose Download to this device, inspect the preview, then choose Prepare download.

Expected: Transfers opens with download preparation progress. Multiple ready files are packaged together.

3. Choose a save location

When the prepared transfer is ready, choose Choose save location and pick a destination file on this device. Wait for the save operation to finish.

Expected: The interface reports saving progress; the saved file is present at the location you selected.

Expected result

  • The selected ready renditions are saved to the chosen device location. Verify the finished save before using the file.

Recovery

  • If the browser cannot open a save-location picker, open Media Nexus in Chrome or Edge.
  • If preparation failed or the prepared artifact expired, inspect the transfer error and use Prepare again after resolving the reported cause.
  • If saving was interrupted within the current session and Resume save is offered, use it to continue the save. Do not treat preparation as a completed download.
