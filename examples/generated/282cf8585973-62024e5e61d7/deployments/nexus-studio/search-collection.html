Search the archive and create a collection

Find indexed media and group selected assets without moving source files.

Deployment: Source review - nexus-studio. macOS / Chrome or Edge.

Deployment configuration

  • canEdit: True
  • collections: True
  • remoteTransfer: True

Prerequisites

  • Archive and Collections must be enabled.
  • Sign in with permission to manage collections. Guest access does not grant collection editing.
  • The archive must contain indexed media.

Steps

1. Search media

Open Archive, enter a known indexed filename or term in Search media and submit the search.

Expected: Search results contain indexed media matching the submitted query; verify the asset names before selecting.

2. Select and create

Select the desired media using the asset selection control. Choose Add to collection, enter a Collection name under OR CREATE NEW, optionally enter purpose or handoff context, then choose Create and add.

Expected: The new collection is created with the selected assets.

3. Verify membership

Open Collections, open the newly named collection, and check that it contains the selected assets.

Expected: Collection members are visible; grouping does not move the source files.

Expected result

  • The selected media appears in the named collection without moving originals.

Recovery

  • If the archive catalog cannot load, use Retry catalog when offered, then repeat the search.
  • If Create and add is disabled, check that Collection name is nonempty. Confirm collection-edit permission with the administrator.
